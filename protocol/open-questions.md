# Open Experimental Decisions

These choices are intentionally unresolved. Implementation must not infer them from the speculative Phi/Psi ontology.

| Decision | Required evidence | Blocks |
|---|---|---|
| Initial excitation modality | Established laboratory method, measurable deposited energy, approved safety boundary | Hardware acquisition |
| Subject material and mediator | Manufacturability, batch control, measurable conventional properties, safe operating range | Coupon design |
| Physical low-DOF mechanism | Named constrained modes, independent measurement, matched normal reference | Low-DOF campaign |
| Effective DOF metric $D_{\rm eff}$ | Units, instrument, calibration, uncertainty, acceptance threshold | Low-DOF qualification |
| Primary response channel | Sensitivity study and conventional causal model | Preregistration |
| Sampling rate and response window | Sensor bandwidth and expected conventional time scales | Acquisition configuration |
| Source isotropy tolerance | Measured source tensor and calibration repeatability | Emitter qualification |
| Energy-matching tolerance | Deposited-energy uncertainty budget | Symmetry comparison |
| Angular tolerance | Fixture and field-map uncertainty | Orientation sweep |
| Minimum relevant effect size | Pilot noise floor and scientific relevance | Sample-size calculation |
| Environmental bounds | Conventional materials characterization | Run acceptance |
| Subthreshold safety ceiling | Approved laboratory procedure and pilot evidence | Energized testing |

## Resolution rule

Resolve each item through a dated protocol amendment containing the decision, evidence, owner, and affected configuration fields. A resolved choice must not silently redefine earlier data.
